# OSINTECA Roadmap

OSINTECA evolves from a curated list into an **OSINT knowledge system for analysts**.

## v0.1 — Unified Atlas
- [x] Migrate the structured OSINT4ALL foundation
- [x] Canonical taxonomy and resource schema
- [x] Source mesh / upstream provenance registry
- [x] Target-input and jurisdiction model
- [x] Evidence, ethics and validation policies
- [x] Trace Labs methodology integration

## v0.2 — Coverage Engine
- [ ] Normalize high-value candidates from registered upstreams
- [ ] Automated canonical-URL deduplication
- [ ] GitHub repository freshness metadata
- [ ] Lifecycle states: active / dormant / archived / superseded
- [ ] Cost, difficulty, requirements, limitations and guide metadata
- [ ] Brazil federal + 27 UF source packs
- [ ] Public-record and registry coverage matrix

## v0.3 — Analyst Interface
- [ ] Searchable GitHub Pages application
- [ ] Filters by input, domain, jurisdiction, access and validation
- [ ] “I have X, what can I do?” decision router
- [ ] Tool comparison by documented features without hidden scoring
- [ ] Evidence-preservation checklist per workflow
- [ ] Offline/exportable catalogue

## v0.4 — Change Intelligence
- [ ] Scheduled link and redirect intelligence
- [ ] GitHub release/archive/ownership change monitoring
- [ ] Diff intelligence for official sources
- [ ] Stale-source review queue
- [ ] Upstream delta reports
- [ ] Monthly catalogue changelog

## v0.5 — AI-Augmented OSINT
- [ ] MCP read-only catalogue server
- [ ] Natural-language tool discovery over validated metadata
- [ ] Citation-preserving RAG over OSINTECA docs
- [ ] Entity/tag suggestions with human approval
- [ ] Duplicate candidate detection

## v0.6 — Investigation Knowledge Graph
- [ ] Resource ↔ input ↔ jurisdiction ↔ use-case graph
- [ ] Separate analyst case graph
- [ ] Evidence nodes and provenance edges
- [ ] Confidence per assertion
- [ ] Timeline and relationship exports

## v0.7 — Academy
- [ ] Progressive analyst missions
- [ ] Sanitized datasets
- [ ] Evidence-quality exercises
- [ ] GEOINT / SOCMINT / CTI / corporate / media verification tracks
- [ ] Trace Labs-inspired challenges
- [ ] Reviewer calibration and contributor onboarding

## v1.0 — Definitive OSINT Library
Definition of done: global discovery atlas, deep jurisdiction packs, searchable UI, structured API, evidence-first playbooks, lifecycle monitoring, knowledge graph, AI-assisted discovery with provenance and community governance.

The metric is not “how many links”. The metric is **how often an analyst reaches a defensible answer faster**.
