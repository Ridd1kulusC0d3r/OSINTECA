# OSINT4ALL → OSINTECA

OSINTECA was bootstrapped from the owner's existing **OSINT4ALL** structured catalogue on 2026-09-30.

The migration keeps the strongest parts of OSINT4ALL: machine-readable resources, intelligence-discipline taxonomy, target-input navigation, validation states, evidence-first methodology, country packs, generated indexes, CI and link-health concepts.

OSINTECA becomes the canonical umbrella project. OSINT4ALL can remain as a historical/source repository until redirects, references and external users are migrated safely.

## Canonical direction

```text
OSINT4ALL (foundation)
         ↓
     OSINTECA
         ├── global source mesh
         ├── structured catalogue
         ├── analyst playbooks
         ├── country/jurisdiction packs
         ├── GitHub Pages search UI
         ├── change intelligence
         ├── AI/MCP discovery layer
         └── Academy / analyst maturity path
```
